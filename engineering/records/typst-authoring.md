# Typst 原生正文与排版验收

2026-11-20 完成正文格式切换，以下为当时的运行结果。公共接口、实现和复现入口见[编辑指南](../../docs/plugins/rendering/typst-editor.md)、[包设计](../../plugins/render/typst/DESIGN.md)和[独立消费者](../../plugins/render/typst/tests/consumer/README.md)。

- 编辑、源码输入与 Agent 共用正文转换和接纳规则。每章保存规范化的 `.typ`，Tiptap 文档及位置按源码修订重建。`/document` 提供独立的解析、生成和位置类型。
- 分章项目书在一个会话内复用固定模板，正文通过动态文件表更新。native 导航返回参与排版的实际源码位置，宿主按编译快照发布编辑器定位、页图和链接。
- 普通排版直接使用素材原件和原生编译入口。项目书演示由宿主选择素材发布版，PDF 保留正文、书签、链接和语义结构。旧源码隐藏、占位和 Markdown 路径已从 Typst 正文编辑中移除。

## 验收证据

- Typst 包 35 个测试文件共 294 项通过，独立安装制品通过。Chromium 分章项目书 13 组、完整源码与审批表 50 组通过，浏览器错误为零。
- 独立读取浏览器下载的四页原生 PDF，核对中文正文、新增表格文字、5 条链接、5 个书签、有标签的文档结构和空附件表。
- 将旧验收快照的备份副本离线转换后，实际宿主重新打开四章并编译出四页与五条链接。原始快照字节保持一致。
- 同一三章项目书、字体和编译制品的 16 次热更新交替采样中，整棵模板替换的中位数为 6.73 ms，动态章节为 5.63 ms。独立进程首次排版分别为 1.02 秒与 1.03 秒，包含宿主和字体的峰值 RSS 分别为 345 MiB 与 346 MiB。采样范围为当时的本机环境。
