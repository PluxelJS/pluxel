# 交付与验收

## 市场部署

- 在目标 Worker + D1 应用迁移，实测目录查询、写入、快照大小和执行成本。演练人工编辑、已确认发行和待办的恢复，用旧编辑请求及旧租约验证写入边界。启用自建 registry 的部署还需通过恢复后的服务下载 D1 所指向的 R2 归档，核对原发行 SHA-512。[恢复范围](foundation.md#保留与恢复)
- 在镜像部署目标对比网页与 Workbench 的搜索、分面、分页及精确发行。记录主站提交到镜像可读的耗时、D1 读取和导入成本，核对同步中断时仍可读、恢复后可见性随之更新。[只读镜像](../../../projects/plugin-market/README.md#只读镜像)
- 在目标使用网络完成一次安装，分别核对市场端点返回的发行与 pnpm 从 registry 得到的字节。已有本地 workerd、镜像和 PNPR 验收的范围见 [Worker 项目](../../../projects/plugin-market/README.md#制品容量与迁移)和 [PNPR 体验指南](../../../docs/development/plugin-market.md)。

## 分阶段验证

| 路径                     | 剩余完成条件                                                                                                                                                                                                                                            |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 带 npm provenance 的收录 | 真实有效证明在目标 workerd 通过，篡改被拒绝，部署方可刷新可信根。将真实 Plugin 的验证结果接入已有的租约事务，证明稍后可读和旧任务提交都有可重查的结果。[目录生产](index-production.md#ci-发布通知与-npm-provenance)                                     |
| 发布材料与 Host 预检     | 用真实发行说明市场展示或 Host 安装还缺哪项事实，能从现有声明读取的字段直接复用。对新增材料用同一 tarball 验证约定的消费者，宿主服务和版本预检须与目标 Host 的接纳结果相符。[发布材料](package-format.md) · [安装预检](installation.md#安装与升级的预检) |
| 持续扫描                 | 第二轮可复用未变观测，通知和复核各有预算，超限单包不阻塞其他工作，进度可恢复。[来源与版本范围](index-production.md#版本覆盖与来源可用性)                                                                                                                |
| 管理界面                 | 需要浏览器编辑时，网页与脚本通过同一 API 处理并发冲突。独立发布管理客户端时校验写入协议的兼容性。[运营编辑](management.md#运营编辑)                                                                                                                     |
| 私有市场消费             | 普通读取权限和管理权限独立，切换主体、市场与来源时正确隔离请求和缓存。[客户端验收](market-client.md#验收条件)                                                                                                                                           |
