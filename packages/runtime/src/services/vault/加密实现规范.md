# Portable Vault v1（@pluxel/runtime 实现说明）

> 代码实现：`packages/runtime/src/services/vault/VaultService.ts`

## 1) 目标与默认行为

- 默认无口令：不设置口令也能用（keyfile slot）。
- 可迁移：复制 `vault.json` + `vault.key` 即可解密使用。
- 跨平台：不依赖系统密钥库。
- 性能优先：运行时解密后驻留内存；大量写入可用 `batch()` 合并为一次加密写入。

## 2) 核心结论：AEAD 自带完整性验证

本实现所有加密与“包裹 DEK”都使用 **AEAD**（当前实现为 `aes-256-gcm`，通过 Web Crypto API `crypto.subtle` 完成）：

- AEAD 产物 = `ciphertext + authentication tag`（tag 作为密文尾部保存）。
- 解密会验证 tag：
  - 密钥错误 / nonce 或 AAD 不一致 / 密文被篡改 → **统一解密失败**。
- 因此“成功解密”同时意味着机密性 + 完整性成立。

工程层面：明文 payload 内包含 `magic: "PV1"`，仅用于格式识别与更清晰的错误提示（不是完整性校验）。

## 3) 密钥模型与术语

- DEK（Data Encryption Key）：随机 32 bytes，用于加密 payload。
- KEK（Key Encryption Key）：用于包裹/解出 DEK（来自 keyfile 或 passphrase 派生）。
- Slot（解锁槽）：每个 slot 存一份 `wrappedDEK` 以及派生 KEK 所需参数。

关键原则：payload 永远只用 DEK 加密；解锁方式只负责得到同一个 DEK。

## 4) 默认解锁方式：Keyfile Slot

- `vault.key`：随机 32 bytes 文件（默认生成）。
- 派生 KEK：HKDF-SHA256（Web Crypto API `HKDF`）
  - `KEK = HKDF(keyfileBytes, salt, info="vault/v1 keyfile", len=32)`
- `wrappedDEK = AEAD_Encrypt(KEK, wrapNonce, AAD, DEK)`

说明：`vault.json` 泄露也无法解密（缺 keyfile）。迁移时带上 keyfile 即可。

## 5) 可选增强：Passphrase Slot（当前实现为 scrypt）

- 派生 KEK：`scrypt(passphrase, salt, N,r,p) -> 32 bytes`（当前使用 `@noble/hashes/scrypt`，以避免依赖 `node:crypto`）
- `wrappedDEK = AEAD_Encrypt(KEK, wrapNonce, AAD, DEK)`

说明：

- `argon2id` 在 v1 规格中保留，但 **当前实现未提供**（会报 `UNSUPPORTED`）。

## 6) Policy（策略）

`policy` 字段：

- `ANY`（默认）：任意一个 slot 解出 DEK 即可。
- `REQUIRE_PASSPHRASE`：只允许 passphrase slot 解锁。
- `2OF2`：必须同时满足 keyfile + passphrase；两者解出的 DEK 必须一致。

## 7) 数据格式（vault.json v1）

### 7.1 顶层结构（最小必需字段）

```json
{
	"v": 1,
	"policy": "ANY",
	"createdAt": "ISO",
	"updatedAt": "ISO",
	"payload": {
		"alg": "aes-256-gcm",
		"nonce": "b64url(24)",
		"aad": "b64url(optional)",
		"ct": "b64url"
	},
	"slots": [
		{
			"type": "keyfile",
			"id": "kf-1",
			"hkdf": { "salt": "b64url(16)", "info": "vault/v1 keyfile" },
			"wrap": {
				"alg": "aes-256-gcm",
				"nonce": "b64url(24)",
				"aad": "b64url(optional)",
				"ct": "b64url"
			}
		},
		{
			"type": "passphrase",
			"id": "pp-1",
			"kdf": { "alg": "scrypt", "N": 16384, "r": 8, "p": 1, "salt": "b64url(16)" },
			"wrap": {
				"alg": "aes-256-gcm",
				"nonce": "b64url(24)",
				"aad": "b64url(optional)",
				"ct": "b64url"
			}
		}
	]
}
```
