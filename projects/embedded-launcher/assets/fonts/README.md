Source: https://github.com/notofonts/noto-cjk/tree/main/Sans/SubsetOTF/SC

Downloaded 2026-10-08 from https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf. The font is embedded in the native executable so Chinese labels do not depend on the host font installation.
