`analysis` 负责事实、计算和局限；`actions` 负责下一步行动。页面、固定章节标题和编号由模板提供。

`[dataField ...]` 是实时数据绑定；`[ref ...]` 按稳定 id 引用对象，不能改成手写编号。
`:::tiptap` 保存复杂表格或模板组件的原生 JSON。允许改指定的组件参数；不要展开、清洗或删掉无关属性。
模板组件 `metrics` 的 props 只接受一个非空字符串 `title`；`dataPath: []` 绑定整份数据。

在消费者项目根目录执行 `vp run report check <工作区目录>` 校验；`render` 可预览未保存候选；`apply` 才保存。
保存后旧工作区仍保留其导出基线，后续编辑请 checkout 到新目录。诊断中的 JSON path 不是 Markdown 行号。
