# 管理工作台

Pluxel 管理工作台优先把空间留给当前任务。导航、插件列表、上下文和日志面板都可以按需展开，不需要一直占用内容区域。

## 主导航

- 桌面端默认使用仅图标导航；悬停或聚焦图标可查看名称。
- 点击左下角的导航按钮可在“仅图标”和“文字导航”之间切换，选择会自动保存。
- 点击桌面侧栏顶部的主题图标可切换明暗模式。
- 手机端固定使用底部导航，不受桌面折叠设置影响。
- 同一领域的多个插件页面可共享一个一级入口；桌面端在独立二级侧栏中切换页面，手机端则使用顶部横向切换条。

进入工作页面后会显示标签栏。当前标签后的 `+` 会用同一页面创建一个干净的新工作标签；接着点击普通导航只会替换
这个新标签，因此原页面会保留。新标签不会复制未保存状态或页面级布局状态，插件列表和分组导航也不再为每一项重复
显示“在新标签打开”按钮。集合页需要打开某个具体对象时，页面自己的打开操作仍会直接创建对象标签。

存在未保存配置时，标签名称旁会显示状态点；关闭最后一个标签会回到首页。

插件 route 需要加入分组时，对同一领域使用相同的 group ID：

```ts
workbenchContract.route('/settings', {
	title: 'Telegram Bots',
	icon: workbenchContract.icons.BrandTelegram,
	order: 65,
	navigation: {
		label: 'Telegram',
		group: {
			id: 'bots',
			label: 'Bots',
			icon: workbenchContract.icons.MessageChatbot,
		},
	},
})
```

分组不会共享或扩大插件的资源授权；每个页面仍只使用所属插件的 Contract 和 grant。

## 插件页面分栏

插件页面可以使用宿主标准化的三段式工作区：左侧对象/导航、中间当前任务、右侧检查器。宽屏边界可拖拽并通过键盘调整；
中等宽度时右侧先变为按需抽屉，窄屏时左侧也变为抽屉，一次只打开一个。切换宽度不会重建页面内容，因此正在输入的
聊天、表单草稿和实时订阅会保留。Shell 会按当前工作标签记住用户调整的尺寸和折叠状态；standalone 页面只在本次打开
期间保留这些偏好。

## 插件目录分类

插件目录中的分类由宿主和真实包来源决定，不写进 `@Plugin`。固定产品可以按结构化 Plugin node address 注册分类，同时用末尾 `*`
包名前缀覆盖以后动态安装的同系列插件：

```ts
workbench: {
	enabled: true,
	pluginGroups: [
		{
			id: 'observability',
			name: 'Observability',
			nodes: [pluginNodeAddressOf(OtelPlugin)],
			packages: ['@pluxel/otel'],
		},
	],
}
```

`nodes` 只接受 `PluginNodeAddressSnapshot`；canonical host module 可以用 `pluginNodeAddressOf(Constructor)` 取得。
`packages` 只接受精确包名或一个末尾 `*` 前缀。没有命中宿主分类的动态第三方
package 会自动以精确 `packageName` 成组，同一包导出的多个插件进入同一分类。用户可以把插件移动到已有分类、调整顺序
或放回未分组，但不能在 Workbench 中创建、重命名或删除分类。这样分类名称和身份始终由宿主或真实包来源提供。

用户布局保存在 Workbench 自己的持久化 namespace，不跟随插件启用状态。把插件拖回其默认分类会清除对应差异偏好；
以后新安装的插件仍会按宿主规则或包名自动归类。

## 插件工作台

进入“插件”时会直接显示完整插件目录，可立即搜索、筛选、调整已有分类或批量操作。打开具体插件后，插件目录会变为可按需展开的左侧面板。

宽屏首次打开插件详情时，插件列表、主内容、右侧上下文和底部实时日志默认同时显示；用户调整后的可见性和尺寸仍会保存到当前浏览器。顶栏布局按钮可以分别显示或隐藏：

- 插件列表；
- 右侧插件上下文；
- 底部实时日志；
- 聚焦模式下的全部周边面板。

分栏边界可以拖拽调整，布局会保存到当前浏览器。手机端使用单面板模式：先在插件列表中选择插件，再通过顶栏按钮返回列表。

常用快捷键：

| 快捷键               | 操作               |
| -------------------- | ------------------ |
| `Ctrl/⌘ + K`         | 打开插件搜索       |
| `Ctrl/⌘ + B`         | 显示或隐藏插件列表 |
| `Ctrl/⌘ + W`         | 关闭当前工作标签   |
| `Ctrl/⌘ + Shift + [` | 切到上一个工作标签 |
| `Ctrl/⌘ + Shift + ]` | 切到下一个工作标签 |
