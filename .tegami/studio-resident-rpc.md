## Replace Studio's business bridge with a resident document API

Studio exposes authenticated local Cap'n Web discovery and client connections, a desktop binary MessagePort capability, and a host runtime entry. Compile requires explicit JSON data; PNG/PDF exports are complete immutable files retained for at least 24 hours. Electron and Pi share the same incremental document service. Remove the previous REST/Fetch bridge and JSON vector encoding and migrate all known consumers together.
