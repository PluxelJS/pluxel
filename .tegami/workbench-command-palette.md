# Workbench command palette and home attention panel

- `Mod+K`（`Mod+P` 保留）打开命令面板：除页面与插件入口外，还能执行布局、文档、明暗主题和键盘帮助等工作区命令；↑/↓ 在结果间移动，Enter 执行所选项。
- 首页新增“需要关注”区块，列出运行异常、依赖阻塞、装配问题、不可用和等待启动的插件及其原因，并显示最近一次失败或未生效的运行更新。
- 首页区分加载中、读取失败（可重试）、尚未注册插件与全部正常四种状态；指标中的“已停止”替换为“需要关注”。
