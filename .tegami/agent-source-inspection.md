# Locate author source from the selected Plugin address

Use `await sdk.plugin(address).inspect()` for the declaration, or select existing `include` and `partPath` sections for Parts, Schema, dependencies, application inputs and package checks. Vite binds the selected application's read-only source backend. Portable Host execution and the Node script owner accept an explicitly installed backend and report its absence; they do not import a compiler or filesystem.

Source results identify the query environment and current disk content, with runtime matching explicitly unverified. Default/fork and generated, source and discovered addresses retain their existing definition identity and distinct invocation evidence. Offline `openProject()` remains available when the application cannot start, for an explicit application selection, workspace discovery and file ownership queries. Detached query types have one owner in the Host agent entry and are re-exported by Rolldown.

`plugins.list({ packageName, definition, limit, cursor })` now returns bounded pages (default 50, maximum 200) with `nextCursor`. Filters apply before status projection. Cursors continue across runs on the same unchanged Host and return `cursor_stale` after query, owner or revision changes. Callers that need every node must consume all pages.

The starter includes a real source inspection script verified by its installed-consumer smoke. Workspace routing, generated AGENTS, the development skill, CLI resources and business scripts use the same default address selection.
