# CLA Signatures

CLA acceptance is tracked in [`signatures.json`](./signatures.json).

Contributors normally do not edit this file by hand. To accept the CLA, read
[`../CLA.md`](../CLA.md), then comment on your pull request:

```text
/approve-cla
```

CI records one entry for the code hosting account that opens the pull request.
Pluxel is currently hosted on GitHub, so current pull requests use
`host: "github.com"`.

```json
{
	"host": "github.com",
	"username": "your-username",
	"acceptedAt": "2026-08-17",
	"claSha256": "<current CLA.md SHA-256>"
}
```

Print the current CLA hash with:

```sh
pnpm cla:hash
```

If Pluxel later moves to Codeberg, approvals should be recorded with
`host: "codeberg.org"` for the Codeberg account that opens the pull request.
