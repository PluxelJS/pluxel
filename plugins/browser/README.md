# 浏览器连接与票据查验

本目录包含浏览器基础能力和一个统一的票据业务包。

| 包                          | 职责                                                                    | 实现约束                             |
| --------------------------- | ----------------------------------------------------------------------- | ------------------------------------ |
| `@pluxel/plugin-playwright` | 连接外部 CDP / Playwright 浏览器，创建有调用方归属的原生 BrowserContext | [连接器设计](./playwright/DESIGN.md) |
| `@pluxel/plugin-invoice`    | VLM 图片提取、财政与税务网站适配、统一查验生命周期                      | [查验设计](./invoice/DESIGN.md)      |

安装和配置见[浏览器连接](../../docs/plugins/browser.md)与[票据查验](../../docs/plugins/invoice.md)。浏览器由部署者独立运行；插件不下载或启动浏览器进程。
