# 浏览器能力与财政票据查验

本目录只分类，不发布聚合插件。应用显式选择下面的包，通过构造器依赖组成能力。

| 包                      | 职责                                                                    | 实现约束                              |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------------- |
| `@pluxel/playwright`    | 连接外部 CDP / Playwright 浏览器，创建有调用方归属的原生 BrowserContext | [连接器设计](./playwright/DESIGN.md)  |
| `@pluxel/fiscal-ticket` | 使用浏览器尝试查验财政电子票据，交付有证据的领域判定                    | [查验设计](./fiscal-ticket/DESIGN.md) |

安装、配置、凭据、取消和示例的公开说明见[浏览器与财政票据](../../docs/plugins/browser.md)。浏览器由部署者独立运行；这些包不安装、下载或启动 Chromium、Lightpanda，也不管理外部浏览器进程。
