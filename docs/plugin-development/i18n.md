---
title: 插件国际化
description: 在插件包内用 Paraglide 编译多语言词条，在服务端与 Workbench renderer 中显式选择语言。
---

Paraglide 把插件包的 JSON 词条编译为带类型的消息函数。已发布的插件和 Workbench 制品携带各自实际用到的消息代码。调用消息函数时传入本次请求或界面的语言。

## 准备插件包

在插件包根目录创建 `project.inlang/settings.json`。

```json
{
	"$schema": "https://inlang.com/schema/project-settings",
	"baseLocale": "en",
	"locales": ["en", "zh-CN"],
	"modules": [
		"https://cdn.jsdelivr.net/npm/@inlang/plugin-message-format@4.6.0/dist/index.js",
		"https://cdn.jsdelivr.net/npm/@inlang/plugin-m-function-matcher@2.4.3/dist/index.js"
	],
	"plugin.inlang.messageFormat": {
		"pathPattern": "./messages/{locale}.json"
	}
}
```

添加 `messages/en.json` 和 `messages/zh-CN.json`。以下是英文词条，中文文件用相同的键和参数名。

```json
{
	"permissions_title": "Permissions",
	"permission_denied": "You cannot perform {action}.",
	"groups": { "count": "Groups: {count}" }
}
```

`pathPattern` 指定相对于包根的单个路径或路径数组。拆分目录时可用 `["./messages/{locale}/common.json", "./messages/{locale}/groups.json"]`。每项在替换 `{locale}` 后指向一个 JSON 文件。嵌套 JSON 对象用点号访问，例如 `m['groups.count']`。 [Inlang Message Format](https://github.com/opral/inlang/tree/main/packages/plugins/inlang-message-format#pathpattern)

在启用 ESM 的插件 `package.json` 中添加私有导入。

```json
{
	"imports": {
		"#i18n": "./.pluxel/i18n/index.js",
		"#i18n/messages": "./.pluxel/i18n/messages.js"
	}
}
```

干净 checkout 后，在插件包根准备 TypeScript 声明。

```sh
vp exec pluxel i18n
vp exec tsc --noEmit
```

可以从其他目录指定 `pluxel i18n --root <package>`，或在自己的 Vite Task 中把类型检查设为依赖此准备命令。 `pluxel build`、Vite 源码模式和 Workbench producer 会自动准备各自用到的包。开发时修改词条会进入相应的 HMR 或 Workbench 制品更新。提交设置和词条，在 Git 中忽略 `.pluxel/`，发包时保留 `dist/`。

## 按请求语言调用

`#i18n` 导出 `m`、`baseLocale`、`locales`、`isLocale`、`resolveLocale` 和 `Locale` 类型。`resolveLocale` 先查精确匹配，再处理大小写和下划线，从右向左去掉子标签直到匹配，最后使用 `baseLocale`。

在 HTTP 路由或指令处理器中先得到本次请求协商后的单个语言标签，然后传给业务方法。

```ts no-twoslash
import { m, resolveLocale } from '#i18n'

export function formatSummary(action: string, count: number, requestedLocale?: string) {
	const options = { locale: resolveLocale(requestedLocale) }
	return `${m.permission_denied({ action }, options)} (${m['groups.count']({ count }, options)})`
}
```

在 Workbench renderer 中使用现有 scope 读取 `host.locale`。Shell 的语言偏好变更后，已打开的 renderer 会收到新值。

```tsx no-twoslash
import { m, resolveLocale } from '#i18n'
import { scope } from './scope'

export default scope.render(function PermissionsManager() {
	const { host } = scope.useWorkbench()
	const locale = resolveLocale(host.locale)

	return (
		<section>
			<h1>{m.permissions_title({}, { locale })}</h1>
			<p>{m['groups.count']({ count: 3 }, { locale })}</p>
		</section>
	)
})
```

在使用处保留字面量词条名和原生 `m` 调用，供 Sherlock 和 inlang CLI 定位消息。 [Inlang CLI](https://github.com/opral/inlang/tree/main/packages/cli#unused-messages)
