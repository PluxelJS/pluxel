Workbench 提供了类似于现代 IDE 的可定制工作区环境。你可以在其中分屏查看不同插件、固定常用业务应用、实时查看结构化日志流，并在插件发生故障时快速定位原因。

## 窗口与布局管理

### 查找与打开入口

- **左侧入口栏**：快速切换业务应用目录、插件管理目录、全局日志与依赖图；
- **快速查找（`Ctrl/⌘ + P`）**：按下快捷键弹出全能搜索框，输入关键字即可快速打开任意页面、插件或面板；
- **分屏与拖拽**：中央文档标签支持自由拖拽分屏、固定（Pin）与多标签分组，便于同时比对配置与业务页面。

<span id="固定常用应用"></span>

### 固定常用应用

在“应用”目录或搜索框中，可以将常用的业务页面一键“固定到侧栏”。固定后，该页面将直接常驻在最左侧图标栏中，下次打开工作台时依然保留。如果后续不再需要，再次右键点击即可取消固定。

### 常用快捷键速查

| 快捷键         | 功能说明                         |
| -------------- | -------------------------------- |
| `Ctrl / ⌘ + P` | 打开快速查找输入框               |
| `Ctrl / ⌘ + B` | 展开或收起左侧边栏               |
| `Ctrl / ⌘ + W` | 关闭当前选中的文档标签           |
| `Ctrl / ⌘ + S` | 保存当前选中的配置分区           |
| `F2`           | 重命名当前标签页的自定义显示名称 |

## 生命周期与故障排查

当插件在界面中显示为异常或未就绪时，可按照以下步骤快速定位：

### 1. 检查插件状态与依赖拓扑

- 在插件管理列表中，绿色圆点表示处于正常 `running` 状态；灰色表示处于停止状态；红色表示启动失败（`start-failed`）；
- 如果插件显示为被阻塞（`dependency-blocked`），点击展开右侧“插件信息”，查看是哪一项依赖未启动或失败。

### 2. 检查配置是否合法

- 如果修改配置后报错，查看字段下方的验证提示，确认输入类型、数字范围或 URL 格式是否符合 Schema 要求；
- 如果配置已保存但行为未变，确认插件是否注册了 `configs.onUpdate()` 动态热应用；若未注册，需手动点击插件卡片右上角的“重启”按钮加载新配置。

### 3. 查看实时日志流

- 打开右侧抽屉中的“最近日志”标签，或点击最左侧导航栏中的“日志”页面；
- 支持按插件名称或日志级别（`error`、`warn`、`info`）进行精准过滤，展开日志条目可查看完整的结构化属性与异常堆栈。
