---
title: 插件目录与分组管理
description: 在 Workbench 插件树中进行手动与自动分组，便于高效管理和检索大型插件集群。
---

随着项目功能增多，应用中可能包含数十个甚至上百个插件。Workbench 提供了可视化的插件目录管理，支持根据依赖关系自动归类，也支持手动创建分组并拖拽排序。

## 查找、多选与排序

在 Workbench 左侧的“插件”列表中：
- **查看详情**：点击插件名称，在右侧主区域打开对应的配置或管理页面；
- **批量多选**：支持使用 `Ctrl / Cmd + 点击` 或 `Shift + 点击` 进行连续范围多选；
- **拖拽排序**：按住行首拖动把手，可在组内调整顺序，或直接拖拽移动至其他分组；
- **批量移动**：选中多个插件后，点击工具栏中的“移动到分组”批量调整归属。

## 智能自动分组

当尚未配置人工自定义分组时，系统会根据插件的必需依赖拓扑进行自动分类：
- **业务主干组**：业务入口插件与仅为它提供服务的私有依赖会自动合并在一组；
- **共享基础设施**：被多个不同业务插件共同依赖的底层模块（如认证、数据库、缓存），会自动收拢到“共享依赖”分组中；
- **独立模块**：没有任何依赖关系的插件会以平铺形式展示。

## 保存与恢复人工分组

点击目录顶部的“编辑分组”按钮，可以自定义添加业务分组标签（例如“订单业务”、“财务结算”、“监控报警”）。
- **实时同步**：分组调整后会自动持久化存储；
- **一键重置**：随时可以点击“恢复自动分组”清除手动设置，重新按依赖拓扑计算布局。
