通过使用 `valibot-form`，你可以在声明 Valibot 配置 Schema 的同时，为字段指定中文标题、说明提示、输入控件与展示分组。Workbench 会直接读取这些元数据生成交互表单，免去为常规配置专门编写前端页面的繁琐工作。

## 先给一个字段加标题

使用 `f.formMeta()` 为字段注入标题与说明：

```ts twoslash
import { BasePlugin, Plugin } from '@pluxel/core'
import * as f from 'valibot-form'
import * as v from 'valibot'

@Plugin()
export class ServicePlugin extends BasePlugin {
	private readonly config = this.configs.use(
		v.object({
			enabled: v.optional(v.pipe(v.boolean(), f.formMeta({ title: '启用服务' })), true),
		}),
	)
}
```

启动插件后，在 Workbench 的配置界面中，该字段将自动呈现为“启用服务”开关组件，默认状态为开启。

> [!TIP]
> **组合规范**
> 使用 `v.optional(v.pipe(baseSchema, metadata), defaultValue)` 可以把默认值和展示元数据一起交给表单。配置页以已保存输入为草稿，默认值和声明来源显示在字段说明中。

## 常用元数据函数

- **`f.formMeta({ title, description, section })`**：基础元数据，设置表单项标签、辅助描述文字及所属分组分段。
- **`f.stringMeta({ placeholder, multiline })`**：字符串配置，提供占位提示或启用多行文本域（Textarea）。
- **`f.numberMeta({ step, min, max })`**：数值控件，设置步长调节器。
- **`f.picklistMeta({ control, labels })`**：枚举选项，支持切换为分段选择器（`segmented`）或下拉选择框（`select`）。
- **`f.arrayMeta({ layout, addLabel })`**：数组列表，提供列表展开与新增项文案提示。

## 在浏览器扩展中使用 AutoForm

WXT 选项页从 embedded Host 读取规则的 Valibot 声明和保存输入，通过 `extractFormFields` 生成字段，并用 `prepareEditableConfigFields(fields, saved)` 根据保存值保护不能安全编辑的字段。保存时，`buildEditableConfigPatch(fields, draft, saved)` 生成差异，扩展将差异和开始编辑时的版本提交给 `host.config.patch`。Host 校验并通知运行中的规则。[WXT 规则设置](https://github.com/PluxelJS/pluxel/tree/main/projects/host-wxt)

## 从字段数据渲染表单

包根的 `extractFormFields` 与 `parseFormFields` 共用只读 `FieldNode`。前者读取本地 schema，后者校验收到的字段数据。把结果传入 `<AutoForm fields={fields} formOpts={opts}>`，在 `opts` 中提供原始草稿初值和提交处理。持有本地 schema 时，可以使用 `<AutoForm schema={schema}>` 直接编辑输入并在提交时自行解析。

`valibot-form/web` 的 `renderers` 为一份表单替换 string、number、boolean 或 picklist 控件。控件拿到真实值路径和原始值，也可委托给 `webRenderers` 中的预制控件。Workbench 配置页用此接口提供「继承」「开」「关」，同一文档的 Content 表单继续使用默认开关。[包的用法与示例](https://github.com/PluxelJS/pluxel/tree/main/packages/valibot-form#web-adapter)
