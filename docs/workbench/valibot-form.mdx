通过使用 `valibot-form`，你可以在声明 Valibot 配置 Schema 的同时，为字段指定中文标题、说明提示、输入控件与展示分组。Workbench 会直接读取这些元数据生成交互表单，免去为常规配置专门编写前端页面的繁琐工作。

## 先给一个字段加标题

使用 `f.formMeta()` 为字段注入标题与说明：

```ts twoslash
import { BasePlugin, Plugin } from '@pluxel/core'
import * as f from 'valibot-form'
import * as v from 'valibot'

@Plugin()
export class ServicePlugin extends BasePlugin {
	private readonly config = this.configs.use(
		v.object({
			enabled: v.optional(v.pipe(v.boolean(), f.formMeta({ title: '启用服务' })), true),
		}),
	)
}
```

启动插件后，在 Workbench 的配置界面中，该字段将自动呈现为“启用服务”开关组件，默认状态为开启。

> [!TIP]
> **组合规范**
> 当字段同时具有默认值与表单元数据时，请使用 `v.optional(v.pipe(baseSchema, metadata), defaultValue)` 结构。让 `v.optional` 位于外层，这样在解包 Schema 时表单引擎依然能正常读取内层的元数据。

## 常用元数据函数

- **`f.formMeta({ title, description, section })`**：基础元数据，设置表单项标签、辅助描述文字及所属分组分段。
- **`f.stringMeta({ placeholder, multiline })`**：字符串配置，提供占位提示或启用多行文本域（Textarea）。
- **`f.numberMeta({ step, min, max })`**：数值控件，设置步长调节器。
- **`f.picklistMeta({ control, labels })`**：枚举选项，支持切换为分段选择器（`segmented`）或下拉选择框（`select`）。
- **`f.arrayMeta({ layout, addLabel })`**：数组列表，提供列表展开与新增项文案提示。
