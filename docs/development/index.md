## 开发调试工作流建议

- **日常逻辑开发**：推荐在业务插件中优先编写纯单元测试或隔离宿主测试（`@pluxel/test`），验证业务逻辑与依赖注入行为。
- **在线服务联调**：使用 `pluxel dev` 启动应用，通过控制台执行交互式运行脚本（`dev run`），并在需要连续修改代码时利用 `dev hmr pause` / `apply` 批次控制确保状态平稳迁移。
- **查阅项目文档**：可通过 `pluxel docs <path>` 查看当前工作区或依赖包自带的离线文档。
