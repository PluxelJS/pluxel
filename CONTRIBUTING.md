# Contributing

Thanks for contributing to Pluxel.

## Contributor License Agreement

Before a pull request can be merged, contributors must accept the project's
[Contributor License Agreement](./CLA.md).

You retain copyright in your contributions.

The CLA grants the project the rights necessary to distribute contributions under
both the GNU Affero General Public License v3.0 and separate commercial licenses.

To accept the CLA, read `CLA.md` and comment `/approve-cla` on your pull request.
CI records that approval in `.cla/signatures.json` on the pull request branch and
then the normal CLA check verifies the file.

## Development

Follow the setup and verification commands in [README.md](./README.md). Changes
that affect user-facing behavior should update `user-docs/` alongside the code.
